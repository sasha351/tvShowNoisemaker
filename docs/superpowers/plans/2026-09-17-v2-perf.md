# v2 Phase 3 — Performance Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make cold detection runs and m4a encodes measurably faster, with every change measured by a repeatable benchmark script rather than assumed.

**Architecture:** Add `tools/bench_perf.sh` (cold detect, warm detect, warm encode, all under `/usr/bin/time -l`). Cache raw `silencedetect` output per (file, window) so silence snapping is free on warm runs. Use ffmpeg's `aac_at` (Apple AudioToolbox) encoder for m4a when present. Record before/after tables in this file.

**Tech Stack:** Python 3.14 stdlib + numpy, ffmpeg (static-ffmpeg), zsh, pytest.

**Spec items handled elsewhere:** spec Phase 3 item 3 ("full-window `detect_by_silence` only for review episodes") is already satisfied by Phase 2: fingerprinted episodes resolve from season consensus and never call `detect_by_silence`; only non-fingerprinted episodes do. Item 5 (GUI multi-folder pipelining) needs the in-process GUI and is part of the Phase 4 plan.

### Task 1: Benchmark script and baseline

**Files:**
- Create: `tools/bench_perf.sh`
- Modify: `docs/superpowers/plans/2026-09-17-v2-perf.md` (this file) — fill the "Before" rows of `## Results`.

**Interfaces:**
- Produces: `tools/bench_perf.sh <season_dir> [format]` — prints one block per run (`cold-detect`, `warm-detect`, `warm-encode-<format>`) with the CLI's stage timings and `/usr/bin/time -l` real/user/sys. Task 4 reruns it unchanged.

- [ ] **Step 1: Write the script**

```zsh
#!/bin/zsh
# Cold/warm timing matrix for one season. Usage: tools/bench_perf.sh <season_dir> [format]
# Cold = ~/.cache/tvshow_noisemaker wiped first (it is only a cache; it refills on the run).
set -euo pipefail
SEASON="$1"; FMT="${2:-mp3}"
ROOT="$(cd "$(dirname "$0")/.." && pwd)"
PY="$ROOT/.venv/bin/python"
OUT="$(mktemp -d /tmp/bench_perf.XXXXXX)"
CACHE="$HOME/.cache/tvshow_noisemaker"

if [[ "$(ls -lO "$SEASON" | grep -c dataless)" != "0" ]]; then
  echo "refusing: $SEASON has iCloud-evicted files (download them first)"; exit 1
fi

timings() {  # stage timings from a plan JSON
  "$PY" -c 'import json,sys; t=json.load(open(sys.argv[1]))["stage_timings"]; print("  stage timings:", " ".join(f"{k}={v:.1f}s" for k,v in t.items()))' "$1"
}
run() {  # label, then the CLI args
  local label="$1"; shift
  echo "== $label =="
  { /usr/bin/time -l "$PY" -m tvshow_noisemaker.cli "$@" --benchmark-fingerprint --log-file "$OUT/$label.log" \
      > "$OUT/$label.out" 2> "$OUT/$label.time"; } || true
  grep -E "Fingerprint benchmark|Stage timings|Total runtime|Converted|Failed" "$OUT/$label.out" | sed 's/^/  /' || true
  grep -E "real|user|sys|maximum resident" "$OUT/$label.time" | sed 's/^/  /'
}

rm -rf "$CACHE"
run cold-detect -i "$SEASON" -o "$OUT/cold" --detect-only "$OUT/cold.json"
timings "$OUT/cold.json"
run warm-detect -i "$SEASON" -o "$OUT/warm" --detect-only "$OUT/warm.json"
timings "$OUT/warm.json"
run "warm-encode-$FMT" -i "$SEASON" -o "$OUT/enc-$FMT" --format "$FMT"
echo "outputs in $OUT"
```

Save as `tools/bench_perf.sh`, then `chmod +x tools/bench_perf.sh`.

```python
def _silencedetect_cache_path(
    filepath: str, silence_db: float, min_silence_len: float, seek: float, limit: Optional[float],
) -> Optional[Path]:
    """Cache path for one raw ``silencedetect`` window; ``None`` when *filepath* cannot be stat'd."""
    try:
        st = os.stat(filepath)
    except OSError:
        return None
    key = "|".join((
        filepath, f"{silence_db:.1f}", f"{min_silence_len:.3f}", f"{seek:.3f}",
        "full" if limit is None else f"{limit:.3f}",
        str(st.st_size), str(st.st_mtime_ns), _CACHE_VERSION,
    ))
    digest = hashlib.sha1(key.encode("utf-8"), usedforsecurity=False).hexdigest()
    return _SILENCE_CACHE_DIR / f"raw-{digest}.json"
```

Then in `_run_silencedetect`, before building `cmd`:

```python
    cache_path = _silencedetect_cache_path(filepath, silence_db, min_silence_len, seek, limit)
    if cache_path is not None and cache_path.exists():
        try:
            data = json.loads(cache_path.read_text(encoding="utf-8"))
            return list(data["starts"]), list(data["ends"])
        except Exception:  # pylint: disable=broad-except
            pass  # unreadable cache entry: fall through and rerun
```

and replace the final `return starts, ends` with:

```python
    if cache_path is not None:
        try:  # ponytail: best-effort cache write, same as _save_cached_silence
            cache_path.parent.mkdir(parents=True, exist_ok=True)
            cache_path.write_text(json.dumps({"starts": starts, "ends": ends}), encoding="utf-8")
        except Exception:  # pylint: disable=broad-except
            pass
    return starts, ends
```

The early `return None` on exception stays before any cache write, so failures are never cached.

```python
@functools.lru_cache(maxsize=None)
def _aac_encoder() -> str:
    """``aac_at`` (Apple AudioToolbox, several times faster than ffmpeg's ``aac``) when this ffmpeg has it."""
    try:
        listing = subprocess.run(
            ["ffmpeg", "-hide_banner", "-encoders"], capture_output=True, text=True, timeout=10,
        ).stdout
    except Exception:  # pylint: disable=broad-except
        return "aac"
    return "aac_at" if " aac_at " in listing else "aac"
```
