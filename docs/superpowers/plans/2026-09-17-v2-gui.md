# v2 Phase 4 — GUI v2 (in-process, review panel) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the subprocess-scraping GUI with one that calls `pipeline.detect`/`pipeline.encode` in-process, encodes confident episodes immediately, and holds flagged episodes in a review panel where the user can listen to each cut, edit it, approve or skip it.

**Architecture:** `processor.py` runs ffmpeg through `Popen` and keeps a registry so cancel can terminate live encodes. `pipeline.detect` gains a `cancel` event and `pipeline.encode` reports per-file outcomes through the progress callback. A new widget-free module `tvshow_noisemaker/review.py` holds the review-row model, time parsing, snippet playback commands, the plan split and a `logging.Handler` that posts to a queue. `gui.py` is rewritten around two worker threads (detect folders in order; encode plan subsets from a queue) and a 100 ms poll of one `queue.Queue` of messages. Spec Phase 3 item 5 (detect folder N+1 while folder N encodes) falls out of the two-thread design.

**Tech Stack:** Python 3.14, customtkinter (installed), tkinter, threading/queue, ffmpeg + `/usr/bin/afplay`, pytest.

- **No new dependencies.** stdlib + numpy + customtkinter (already required). No pytest plugins.
- **`from __future__ import annotations`** at the top of every module.
- **Keep customtkinter** (user decision). Appearance "system", theme "blue".
- **Log lines other code scrapes must survive verbatim:** `"Starting conversion  (%d files, ..."`, `"  ✓ Done in ..."`, `"  ✗ Skipped – ..."`, `"  ✗ Failed – ..."`, `"Fingerprint boundaries"`, `"Chromaprint result"`, `"Could not determine duration"`. (The GUI stops scraping them; the CLI and its tests still print/assert them.)
- **Confidence values** are exactly `"high" | "review" | "skip"`; **source** values exactly `"config" | "fingerprint" | "silence" | "manual"`. A user-edited cut gets `source="manual"`, `confidence="high"`; a skipped row gets `confidence="skip"`.

- **Cancel** must leave no orphan ffmpeg: `pgrep ffmpeg` is empty a second after cancel.
- **Time fields** display and parse `m:ss.s` (`"1:23.4"`); hours are not needed (episodes are under an hour... but `parse_time` must also accept `h:mm:ss.s` so a pasted value never silently breaks).
- **Output folder per source folder** stays `output_subdir_for(folder, dest)` = `<dest>/<basename> (Audio)`.
- **Existing test style:** `unittest.mock.patch("<module>.<name>")` at the *using* module, `MagicMock`, `tmp_path`, touched empty `.mp4` files.
- **Ponytail:** minimal code, mark deliberate shortcuts with `# ponytail:` comments.

```python
# Live ffmpeg encodes, so a GUI cancel can terminate them instead of waiting up to 10 minutes.
_live_ffmpeg: set = set()
_live_lock = threading.Lock()


def terminate_all() -> int:
    """Terminate every ffmpeg started by :func:`process_file` that is still running."""
    with _live_lock:
        procs = list(_live_ffmpeg)
    for proc in procs:
        try:
            proc.terminate()
        except Exception:  # pylint: disable=broad-except
            pass
    return len(procs)
```

```python
"""Widget-free pieces of the GUI review flow: time fields, review rows, snippet playback, log relay."""
from __future__ import annotations

import dataclasses
import logging
import os
import queue
import subprocess
import tempfile
import threading
from dataclasses import dataclass
from typing import List, Optional, Tuple

from tvshow_noisemaker.pipeline import EpisodePlan, Plan


def parse_time(text: str) -> float:
    """``"1:23.4"`` / ``"0:01:23.4"`` / ``"83.4"`` → seconds. Raises ValueError on anything else."""
    parts = text.strip().split(":")
    if not text.strip() or len(parts) > 3:
        raise ValueError(f"not a time: {text!r}")
    total = 0.0
    for part in parts:
        value = float(part)
        if value < 0:
            raise ValueError(f"negative time: {text!r}")
        total = total * 60 + value
    return total


def format_time(seconds: Optional[float]) -> str:
    if seconds is None:
        return ""
    minutes, secs = divmod(round(seconds, 1), 60)
    return f"{int(minutes)}:{secs:04.1f}"


def split_plan(plan: Plan, review_all: bool) -> Tuple[List[EpisodePlan], List[EpisodePlan]]:
    """(episodes to encode now, episodes for the review panel)."""
    if review_all:
        return [], list(plan.episodes)
    review = [ep for ep in plan.episodes if ep.confidence == "review"]
    now = [ep for ep in plan.episodes if ep.confidence != "review"]
    return now, review


@dataclass
class ReviewRow:
    episode: EpisodePlan
    intro_start: str
    intro_end: str
    outro_start: str
    skip: bool = False

    @classmethod
    def from_episode(cls, ep: EpisodePlan) -> "ReviewRow":
        return cls(ep, format_time(ep.intro_start), format_time(ep.intro_end), format_time(ep.outro_start))

    def to_episode(self) -> EpisodePlan:
        """A copy of the episode with the edited cuts applied; blank fields stay None."""
        ep = dataclasses.replace(self.episode, flags=list(self.episode.flags))
        edited = False
        for name in ("intro_start", "intro_end", "outro_start"):
            text = getattr(self, name).strip()
            value = parse_time(text) if text else None
            if value != getattr(self.episode, name):
                edited = True
            setattr(ep, name, value)
        ep.source = "manual" if edited else ep.source
        ep.confidence = "skip" if self.skip else "high"
        return ep


def snippet_cmd(path: str, t: float, out_wav: str, span: float = 6.0) -> List[str]:
    start = max(0.0, t - span / 2)
    return ["ffmpeg", "-y", "-ss", f"{start:.1f}", "-t", f"{span:.1f}", "-i", path, "-vn", "-ac", "2", "-ar", "44100", out_wav]


class SnippetPlayer:
    """Play a short snippet around a cut: ffmpeg → wav in a temp dir → afplay, on a thread."""

    def __init__(self) -> None:
        self._proc: Optional[subprocess.Popen] = None
        self._dir = tempfile.mkdtemp(prefix="tvshow-snip-")

    def play(self, path: str, t: float) -> None:
        self.stop()
        threading.Thread(target=self._play_blocking, args=(path, t), daemon=True).start()

    def _play_blocking(self, path: str, t: float) -> None:
        wav = os.path.join(self._dir, "snippet.wav")
        subprocess.run(snippet_cmd(path, t, wav), capture_output=True, timeout=60)
        self._proc = subprocess.Popen(["afplay", wav])  # ponytail: macOS only, like the folder picker
        self._proc.wait()

    def stop(self) -> None:
        proc, self._proc = self._proc, None
        if proc is not None and proc.poll() is None:
            proc.terminate()


class QueueHandler(logging.Handler):
    """Relay log records to the GUI thread as ``("log", line)`` messages."""

    def __init__(self, q: "queue.Queue") -> None:
        super().__init__()
        self._q = q

    def emit(self, record: logging.LogRecord) -> None:
        self._q.put(("log", self.format(record)))
```

**Message protocol** (one `queue.Queue`, polled every 100 ms on the Tk thread; every tuple's first element is the kind):

| message | from | meaning |
|---|---|---|
| `("progress", folder, stage, done, total, text)` | either worker | update status card / feed |
| `("plan", folder, plan)` | detect worker | folder detected: split, queue confident subset, add review rows |
| `("detect_failed", folder, reason)` | detect worker | folder skipped |
| `("encoded", folder, summary)` | encode worker | one encode job finished |
| `("log", line)` | `QueueHandler` | details log line |
| `("idle",)` | encode worker | encode queue drained and detect worker finished |

**Threads:**
- `_detect_worker(folders)`: for each folder in order: `plan = detect(folder, cfg, progress=self._progress_for(folder), cancel=self.cancel)`; on exception post `detect_failed`; if `self.cancel.is_set()` stop; else post `("plan", folder, plan)`. When done, put `None` on `self.encode_jobs` after any jobs already queued... no — instead set `self._detect_done = True` and put a sentinel `("flush",)` on the encode queue so the encode worker knows no more folders are coming.
- `_encode_worker()`: loop `job = self.encode_jobs.get()`; `job` is `(folder, Plan, out_dir)` or the flush sentinel; on a job: `summary = encode(plan, cfg_for(folder), out_dir, progress=self._progress_for(folder), cancel=self.cancel)`; post `("encoded", folder, summary)`. On the sentinel: if no review rows are pending → post `("idle",)` and exit; otherwise keep waiting (approvals enqueue more jobs; "idle" is posted when the last approved job finishes and no rows remain).
- Encode pool size while detection is still running: `Config(..., workers=max(1, cpu - cpu // 2))`; after detection finished: `workers=None` (pipeline default). `cpu = os.cpu_count() or 2`.

"Export approved cuts…" writes `Plan(input_dir=folder, episodes=approved_eps_for_that_folder).save(path)` for the folder of the first remaining row (or the last approved folder) via `filedialog.asksaveasfilename(defaultextension=".json")`; the GUI keeps `self.approved: dict[str, list[EpisodePlan]]`.

**Start / Cancel:** Start clears state, creates `self.cancel = threading.Event()`, `self.encode_jobs = queue.Queue()`, installs `QueueHandler` (formatter `"%(asctime)s [%(levelname)s] %(name)s: %(message)s"`, level INFO) on `logging.getLogger("tvshow_noisemaker")`, starts both threads, disables folder editing, turns the button into "Cancel".
